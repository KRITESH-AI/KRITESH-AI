### AI-Powered Intelligent Hiring Assistant

An AI-powered recruitment platform that streamlines the hiring process by combining Machine Learning, Natural Language Processing (NLP), Semantic Search, Retrieval-Augmented Generation (RAG), and Google Gemini AI. The application evaluates resumes against job descriptions, calculates ATS scores, provides explainable hiring recommendations, and enables recruiters to interact with an intelligent AI Hiring Assistant.
